WHAT HAPPENED
================================================================
The threat actor obtained a shell as the svc_api service account
(entry vector not yet determined — potential web app exploit or
credential stuffing against the API endpoint).

From the svc_api shell, the attacker:
  1. Enumerated local users and SUID binaries
  2. Exploited a SUID misconfiguration on /usr/bin/find to gain root
  3. Read /etc/shadow (credential dumping)
  4. Created backdoor user 'it_support' with sudo rights
  5. Harvested SSH private keys from /home and /root
  6. Installed cron persistence: /etc/cron.d/svc-updater (fires every 10 min)

================================================================
INVESTIGATION SCOPE — OPEN QUESTIONS
================================================================
The initial access vector has not yet been confirmed. Working hypotheses:
  - Credential stuffing against the internal API endpoint
  - Reuse of credentials or keys from a previously compromised host

These questions must be answered by the SOC investigation team.
